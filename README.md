# Sistem Perawatan Tanaman

## Deskripsi
Sistem Perawatan Tanaman adalah aplikasi yang dibuat menggunakan
bahasa pemrograman Java untuk membantu pengguna dalam mengelola
data dan kegiatan perawatan tanaman

Project ini dibuat sebagai tugas mata kuliah Pemrograman
Berorientasi Objek (PBO) dengan menerapkan konsep Object-Oriented
Programming (OOP)

## Fitur
- Menambahkan data tanaman
- Menampilkan data tanaman
- Mengubah data tanaman
- Menghapus data tanaman
- Mengelola perawatan tanaman

## Konsep OOP
Konsep OOP yang digunakan dalam project ini:
- Class
- Object
- Encapsulation
- Inheritance
- Polymorphism

## Teknologi
- Java
- Visual Studio Code
- GitHub
